# Essential: Stack Your Leverage — Code is Your Asset

Source: Discord conversation with mentor Tom, 2026-07-26. The third pillar of
the operating philosophy. Treat as an essential.

## The core principle
The biggest assets you have are **skills** and **the code you've made before**.
"Code from scratch is cheap; code you hold is valuable."

## The rules
1. **Stack your good code.**
   - One design you've made that you think is really nice and valuable becomes
     a design token for the LLM.
   - The more your code gets better, the more you're left with an asset worth
     more than gold.

2. **You don't need to know it's GOOD code, just that it's a GOOD OUTPUT.**
   - To improve it without looking at it: "This design we have looks really
     good. Help me improve and generalize the code for this, while keeping the
     design output we have today."

3. **The compounding effect.**
   - 2 hours to get a good extension out the first time.
   - 20 minutes for the next one.
   - 30 seconds to get an extension out — because you just tell it to look back
     at your old code and practices.

4. **The skill-capture workflow (after a session).**
   - "Recall what we've done and capture everything into skills into a separate
     folder. Do your due diligence to make sure we capture all of the small
     stuff and edge cases we've covered across the session."

5. **The leverage loop (for side gigs / passive income).**
   - Let it try something impossible first. See what tools and skills it needs
     (browser use, computer use, API access).
   - Once it does it once really well, let it do it again 2-3 more times to get
     out the edge cases.
   - Then capture everything into skills.
   - Abuse it with sol/opus for spreadsheet, video, motion design consulting.
   - Find the arbitrages closest to you (landscaping, CAD, blender assets, 3D
     stencil models) — easier to start and gives a pattern to create skills.

6. **Leverage comes in different forms other than money.**

## What this means for our setup
- The drain + pack-foundations IS this: stacking code into reusable skills.
- Every foundation squeezed is a "code you hold" asset.
- The skill-capture after sessions (capture edge cases into skills) is exactly
the pattern we're automating.
- Don't obsess over templates/workflows — obsess over stacking good code and
  outputs into skills.
