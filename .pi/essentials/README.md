# Essentials — Operating Philosophy

The operating philosophy (from mentor Tom) that guides how we work. These
guide *how* we approach work without over-restricting behavior.

## The synthesis (start here)
- `operating-philosophy.md` — the unified guide combining all three pillars.

## The three pillars
- `guiding-small-model.md` — Pillar 1: code is ground truth, skills are the
  shortcuts. How to feed the small model (deepseek-flash) so it works without
  mistakes.
- `steer-outcomes-not-behavior.md` — Pillar 2: don't over-restrict the agent;
  convert patterns into CI checks, let it rampage, verify outcomes.
- `stack-your-leverage.md` — Pillar 3: code is your asset; stack good code into
  skills; the compounding effect; skill-capture after sessions.

## How to use
- Read `operating-philosophy.md` when deciding how to approach a task.
- The drain + pack-foundations IS Pillar 3 in action.
- The 7-gate foundations-workflow IS Pillar 2 in action.
- Feeding the small model foundation leaves IS Pillar 1 in action.
