# Pack: Foundations

Reusable proven code, encoded from indexed inspiration repositories. Each leaf answers: what the repo solves, the reusable primitives (with graph anchors), and the exact skill-line for reuse. Pick at most 2 members matching the task, most specific first; read each fully. Each leaf is a lean surface (solves + skill-lines); load its `references/DEEP.md` only when porting a primitive. Users may invoke any leaf directly via `/skill:<name>`.

## Members

- foundations-workflow: author foundation skills from a memory-graph repo (graph-first, source-confirmed)
- billion-context-pi-foundation: long-context delegation, compress/decompress, watchdog
- browser-harness-foundation: CDP daemon, page helpers, recorder, video composition
- browser-use-foundation: LLM browser agent, DOM serialization, tool registry
- localterm-foundation: terminal rendering, secret-scrubbed bash, streaming redaction
- pi-fabric-foundation: Schema guard, budget ledger, compaction bounds
- pi-upstream-foundation: agent loop, branch-summarization compaction
- pydantic-ai-harness-foundation: capability/toolset, compaction strategies, spend budget
- mem0-foundation: agent memory, metadata filters, vector stores
- jobspy-foundation: multi-site job scraping (linkedin/glassdoor/naukri/bayt/bdjobs)
- linkedin-mcp-foundation: LinkedIn as MCP server, session state, cookie bridge
